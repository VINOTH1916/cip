# CIP: Creative Image Processing for Captioning and Face Recognition

A machine learning-powered project for generating descriptive captions from images, detecting objects, recognizing faces, and enabling smart semantic image retrieval.

This project was developed as a pre-final year project and focuses on building a prototype for intelligent image understanding and search. Instead of relying only on file names or manual tags, the system extracts visual features, descriptions, and metadata from an image to support faster and more semantic search.

## Project overview

The core idea is to turn an image into structured information that can be searched intelligently:

- generate a caption from the image content
- detect objects present in the image
- analyze face attributes such as age, gender, and emotion
- extract dominant colors from detected person regions
- store and retrieve image metadata semantically using sentence embeddings

This enables a workflow where users can search for images using natural language queries such as:

- "a person smiling outdoors"
- "a red car parked near a tree"
- "images with faces and people"

## Key features

### 1. Image caption generation
The project uses a VisionEncoderDecoder model based on ViT + GPT-2 to generate descriptive captions for images.

### 2. Object detection
YOLO is used to detect common objects in the image and count how many instances of each class are present.

### 3. Face recognition and analysis
The project integrates DeepFace (with OpenCV detector backend) to estimate:

- age
- gender
- dominant emotion

### 4. Color analysis
Using segmentation and clustering, the code extracts dominant colors associated with detected persons or regions.

### 5. Semantic search
Sentence embeddings generated by SentenceTransformer (all-MiniLM-L6-v2) enable similarity-based retrieval across captions and text descriptions.

### 6. Web interface
The app exposes a simple Flask-based interface where users can upload an image and receive extracted metadata and predictions.

## Model components

### Image captioning
- Model: BLIP / ViT + GPT-2 based image captioning
- Input: image
- Output: natural language caption

### Object detection
- Model: YOLO
- Input: image
- Output: detected objects with labels and counts

### Face recognition
- Library: DeepFace
- Input: image
- Output: face analysis (age, gender, emotion)

### Semantic embedding
- Model: SentenceTransformer (all-MiniLM-L6-v2)
- Input: text or caption
- Output: embedding vector for semantic comparison

### Classification / clustering
- KNN
- KMeans

## Setup instructions

### 1. Clone the repository

```bash
git clone https://github.com/VINOTH1916/cip.git
cd cip
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate    # Linux/Mac
# or
venv\Scripts\activate       # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements/requirements.txt
```

### 4. Run the application

```bash
python image_to_captions.py
```

Then open the app in your browser at:

```text
http://localhost:5007
```

## Usage

1. Open the web app.
2. Upload an image.
3. The system processes the image and returns:
   - generated caption
   - detected objects and counts
   - face analysis
   - color information
4. The metadata can be used for searching and indexing image content.

## Notes

Potential future enhancements include:

- a database-backed image index
- better face identification and recognition
- improved semantic retrieval UI
- deployment as a web service or cloud app
- support for batch image processing
- user authentication and saved search sessions
